# Java Backend Engineering Journey

This repository documents my AI-assisted learning journey through Java and
Spring Boot backend engineering. The work is organized into focused modules,
beginner-friendly examples and short daily learning logs.

## Repository structure

- `java-foundations/` contains core Java language, JVM and backend fundamentals.
- `daily-log/` records what was learned and implemented.

## Java foundations

- [Java foundations](java-foundations/README.md)
- [01 - JVM execution](java-foundations/01-jvm-execution/README.md)

This repository starts with standard Java and does not use Spring Boot,
external libraries or Java packages in its current foundational exercises.
